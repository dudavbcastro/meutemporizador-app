# Meu Temporizador

Aplicação desenvolvida em HTML, CSS e JavaScript para gerenciamento de sessões de foco utilizando a Técnica Pomodoro. O projeto permite configurar o tempo de estudo em minutos e segundos, iniciar, pausar e reiniciar o cronômetro, com alerta sonoro ao término. Instalável como PWA (Progressive Web App).

## Funcionalidades
- Configuração de tempo personalizado (minutos e segundos)
- Controles de iniciar, pausar e resetar
- Alerta sonoro ao término do tempo
- Cálculo preciso mesmo com a aba em segundo plano
- Instalável como aplicativo (PWA)
